# Backend Node.js asli — arsip referensi saja

Folder ini mempertahankan backend Node.js yang terdapat di ZIP asli untuk kebutuhan audit dan pembandingan migrasi. Ini **bukan backend aktif** dan tidak boleh dijalankan bersamaan dengan backend Python.

Backend aktif yang didukung paket ini berada di `backend/` (FastAPI). Skema PostgreSQL asli dipindahkan dan dikembangkan pada `backend/migrations/`.
